# Urban Grammar implementation roadmap

1. Validate district DNA and Street Family taxonomy in a small read-only planning scene.
2. Implement deterministic block plans for Residential and ArchiveOS only; review Block and Street before new asset production.
3. Add density and skyline sampling with camera-visible repetition limits.
4. Implement landscape, vehicle, and human instancing contracts.
5. Add simulation interfaces for traffic, signal, pedestrian, weather, night, and events without enabling simulations yet.
6. Review District then City composition before any canonical promotion.

No phase may generate large asset batches until its immediately preceding review gate passes.

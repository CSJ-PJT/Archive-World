# Archive City Master Build — Phase 2

## Scope and Gate

This phase establishes an intelligence and planning contract, not a city-layout or asset-production pass. The source chain is **Reference Intelligence → Building Genome → Urban Genome → City Factory plan → review gate**. Incoming references remain reference-only; no source mesh is copied or promoted.

| Area | Deliverable | Status |
| --- | --- | --- |
| Reference Intelligence | 43-reference index and DNA dimensions | complete contract |
| Building Genome | composable module schema | complete contract |
| Urban Genome | block/street/district/city rule schema | complete contract |
| District DNA | seven district-level urban roles | plan-only |
| Ecosystems | Street 150+, Landscape 100+, Vehicle 80+, Human 100+ taxonomy | target only |
| Metrics | planning-proxy contract | complete contract |
| Simulation | future-layer I/O skeleton | design-only |

## Hard Gates

1. **Reference → Grammar:** provenance and license status must exist; direct mesh copying is prohibited.
2. **Grammar → Genome:** a candidate must change at least seven architectural dimensions before it can be called original.
3. **Genome → Block:** a valid street graph, separated service access, daylight/spacing proxy, and review metrics are required.
4. **Block → District:** Building, Family, Block, Street, District, and City review gates are all required.
5. **District → City:** requires a separate explicit approval. This repository phase does not alter the 1,633-instance V3 layout, canonical assets, or runtime manifests.

## Approval Stop

The next blocked action is creating or promoting actual Building/Street/landscape families, or applying reviewed plans to a District/city layout. Those actions require user approval.

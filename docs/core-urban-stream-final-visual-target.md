# Core + Urban Stream Final Visual Target

첨부 비교 이미지는 실제 구현물이 아니라 V9/V10과 목표 상태의 품질 차이를 설명하는 `CONCEPT TARGET`이다.

> Concept reference is used only for abstract spatial and visual-quality guidance. No direct reproduction of identifiable architecture, waterway design, bridge design, lighting arrangement, or urban plan is permitted.

Archive Grammar로 변환할 일반 원칙은 다음과 같다.

- 중심 skyline peak, Ledger secondary peak, 수변 저층부의 수직적 대비
- upper street, lower promenade, shallow water bed가 구분되는 다층 도시 단면
- 수로 양안의 transparent lobby, arcade, terrace, public frontage
- 수로·광장·교량·Transit lobby를 잇는 연속적인 보행축
- daylight, dusk, night가 서로 다른 실제 조명 상태
- 사람·차량·식재·가로시설이 장소와 동선을 설명하는 밀도
- procedural wet/dry stone, warm lobby, blue-gray water, restrained Archive accent
- 근거리 품질은 actual geometry, 원거리 품질은 instancing과 LOD로 분리

복제 금지 항목은 특정 교량 silhouette, 수로 폭·선형, 특정 건축 facade, 실제 간판·조형물, 조명 위치 및 식재 배열이다. 최종 생성물의 originality 상태는 `ARCHIVE_NATIVE_PROCEDURAL_NO_DIRECT_COPY`로 기록한다.
